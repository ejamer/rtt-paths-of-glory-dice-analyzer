Paths of Glory — Dice Analyzer

Upload a saved game-log page and see how random the dice really were.

Nothing you upload ever leaves your browser. This page never uploads your file anywhere — it's read locally and parsed on your device. There's no server, no account, no tracking. That's also why you have to save the file yourself: this tool can't (and won't) fetch a game from Rally the Troops on your behalf, since that would require it to bypass Rally's login.

Log into your game on Rally the Troops, then File → Save Page As → "Webpage, Complete" (this is the one that works — "HTML Only" and "Single File" don't capture the game data). Drop the resulting .htm file here — you can ignore the _files folder saved alongside it.
How this works / what it looks for

Every die roll in a Rally the Troops Paths of Glory game log is an empty <span class="die {ap|cp} d{1-6}"> — the class attribute carries the side and the raw value. This tool classifies every roll into one of five categories from the text around it:

  • Mandated Offensive — the per-turn CP/AP roll that assigns which power must attack
  • Combat Fire — attacker's/defender's fire in a battle, tagged with which role rolled it
  • Entrench — voluntary entrenchment attempts
  • Flank Attempt
  • Siege

If a roll doesn't match any of those five (e.g. the site's HTML changed, or a roll type this tool doesn't know about yet), you'll see a warning banner above with the count — everything else is still parsed correctly.

This is the browser port of a small local Python pipeline (parse_dice.py / build_report.py) — see the repo README for details.
